# IA II – Activity 1: professor's announcement (verbatim)

Dear Students,

Please find below the instructions for IA II – Activity 1 (20 Marks): Agentic AI System using Modern LLM-based Tools.

Group Size: 3 students, from the same lab batch.

What you need to do:
Build a small Agentic AI system where an LLM acts as an autonomous agent that understands a goal, plans steps, uses tools (search, calculator, documents, etc.), and produces an output. The focus is on tool usage, reasoning, and orchestration — not model training.

Your submission must cover three parts:
1. Agent Design – goal, role, tools used, memory type, planning strategy
2. Implementation – one LLM-based agent, at least two tools, multi-step reasoning, and observable agent behavior (logs/traces)
3. Analysis & Comparison – compare your modern agent with a classical rule-based agent (as per syllabus)

Deliverables:
- PDF report (5–10 pages)
- Architecture/tool flow diagram
- Code repository or notebook, with a demo of the working agent
- Agent interaction logs
- Prompts and output screenshots

The complete instruction document is attached for your reference. Please go through it carefully.
